# IPL Matches Exploratory Data Analysis & Data Cleaning

A professional Data Analysis project demonstrating fundamental Pandas data manipulation, inspection, and cleaning workflows on the Indian Premier League (IPL) matches dataset (spanning from 2008 to 2024).

---

## 📌 Project Overview

This notebook demonstrates key Exploratory Data Analysis (EDA) and Data Cleaning techniques using `pandas` on cricket match records:
- **Environment Setup & Verification:** Package installation and library imports.
- **Dataset Loading:** Reading structured data from CSV files.
- **Initial Data Inspection:** Evaluating structural dimensions, head/tail samples, column schema, and data types.
- **Data Cleaning & Preprocessing:** Identifying duplicates, assessing missing values, multi-column indexing, and feature dropping.
